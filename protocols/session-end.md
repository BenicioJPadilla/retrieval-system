# Session end

Before finishing a substantive session:

1. **Decisions** made, with rationale: `/vault-add` as `type: decision`.
2. **Open threads / next actions**: append to the project's note in `vault/projects/`.
3. **New people, clients, tools, where credentials live** (never the credentials themselves): `vault/people-and-clients/` or the project note.
4. **Reusable process you just figured out**: `vault/workflows/`.
5. `/vault-sync`.

Skip for trivial sessions (one-line fixes, Q&A). Never store credentials in the vault.
